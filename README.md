# RNN-Based Sequence Classifier

## Project Overview

This project develops a Recurrent Neural Network (RNN) based
sequence classifier.

The model learns to classify numerical sequences into increasing
and decreasing patterns.

## Objective

- Build an RNN sequence classifier.
- Experiment with different sequence lengths.
- Evaluate the predictions.
- Apply the trained model to new sequences.

## Sequence Classes

Class 0 - Decreasing sequence

Class 1 - Increasing sequence
